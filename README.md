One line: a one-star review of Monday, written as if Monday were a restaurant.

> One star. Monday sat me by the fire exit, served my coffee cold, and charged me for the weekend I never got.

Entry for the [One Star for Monday](https://make.fun/bounty/u-clever-harbor-75-one-star-for-monday-9ead4a61) bounty on make.fun.

## Run

```sh
python3 main.py
```

Writes the line to `$ENTRY_OUTPUT_DIR/entry.txt` (default `/output`).
